# 冷链温度异常应急处置（演示资料）

## 异常判定

冷链异常包括车辆制冷故障、温度记录中断、车厢长时间开门、商品中心温度超出品类要求以及包装内大量结露。发现异常时，配送员不得自行删除或修改温度记录，应立即上报配送中心。

## 现场处置流程

1. 记录发现时间、车辆、配送单、门店 ID 和当前温度。
2. 减少开门，保持商品原有包装，并将异常批次与正常批次分开。
3. 配送中心联系门店说明情况，必要时调整配送顺序或安排备用车辆。
4. 到店后由门店复测温度并检查外观、气味和包装状态。
5. 根据商品种类、超温幅度和持续时间决定正常接收、降级接收、隔离待检或拒收。

## 品类提示

叶菜短途配送通常建议保持 0～5℃，但不得因追求低温造成冻结。香蕉等热带水果对低温敏感，不应简单套用叶菜温区。冻品如果出现明显解冻、包装渗液或反复冻融迹象，应优先隔离并交由质量人员处理。

## 复盘要求

异常结束后应检查车辆制冷设备、装卸时长、路线拥堵和人员操作。系统记录至少包含温度曲线、异常持续时间、受影响批次、处置结果和责任节点，用于后续优化路线和设备维护计划。
