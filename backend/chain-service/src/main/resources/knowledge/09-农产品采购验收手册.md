# 农产品采购与到货验收手册（演示资料）

## 一、采购前检查

采购人员应确认供应商状态、产地信息、预计采收日期、运输方式和到货时间。需要冷链运输的商品，应在订单中明确要求温度区间、车辆清洁要求和温度记录方式。叶菜、食用菌、浆果等高损耗商品不宜一次采购过多，应结合门店销量和库存周转天数安排采购量。

## 二、到货验收步骤

1. 核对采购单、供应商、批次号、门店或配送中心 ID。
2. 检查车辆卫生、外包装完整性以及是否存在雨淋、污染和异味。
3. 抽测商品中心温度，并与运输温度记录进行比对。
4. 按品类检查色泽、成熟度、硬度、腐烂、虫害和机械损伤。
5. 记录实收数量、拒收数量、异常比例、现场照片和处理人。

## 三、常见异常处理

少量外包装破损但商品本身合格时，可以更换包装后接收，并在验收记录中备注。出现大面积腐烂、化学品异味、温度严重超标或来源信息不完整时，应隔离该批次并暂停入库。数量不符时，以现场复核结果为准，同时通知采购人员和供应商确认差异。

## 四、系统记录建议

演示系统中可使用“批次号 + 供应商 + 到货日期”作为追溯主线，并关联配送单、门店 ID、验收结果和异常照片。所有拒收、降级接收和报损操作都应保留原因，不能只修改库存数量而不留下记录。
